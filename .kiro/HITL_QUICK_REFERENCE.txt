## ENABLE INTERACTIVE MODE

  fathom run "your intent" --interactive --use-xml --serial emulator-5554 -v
  
  Short form:
  fathom run "your intent" -i -x -s emulator-5554 -v


## SAMPLE COMMANDS

1. Basic Interactive Mode:
   fathom run "Open Gmail" -i -x -s emulator-5554 -v

2. Complex Task with Guidance:
   fathom run "Login to Gmail and check unread emails" -i -x -s emulator-5554 -v

3. E-commerce Checkout:
   fathom run "Complete checkout with test card" -i -x -s emulator-5554 -v

4. Form Filling:
   fathom run "Fill registration form" -i -x -s emulator-5554 -v


## WHAT HAPPENS IN INTERACTIVE MODE

✅ Agent asks questions when uncertain (confidence < 50%)
✅ You can pause and inject context anytime
✅ Agent re-analyzes with your guidance
✅ Context affects LLM reasoning immediately
✅ Execution resumes from exact same point


## INTERACTIVE MENU (When Paused)

  ⏸️  Execution Paused
  
  Options:
    1. Resume execution          → Continue without changes
    2. Inject additional context → Provide guidance to agent
    3. Cancel execution          → Stop and exit


## AGENT QUESTION EXAMPLE

  ❓ Agent Question
  ┌────────────────────────────────────────────────────────────┐
  │ The agent is uncertain (confidence: 45%) about what to do  │
  │ next.                                                       │
  │                                                             │
  │ Current screen: com.example.app.LoginActivity              │
  │ Intent: Login to the app                                   │
  │ Suggested action: Tap on Element at [500, 800]            │
  │                                                             │
  │ What should the agent do?                                  │
  └────────────────────────────────────────────────────────────┘
  Your answer: _


## CONTEXT INJECTION EXAMPLES

Good context examples:
  ✓ "The login button is at the bottom of the screen"
  ✓ "Use test@example.com as the email"
  ✓ "Skip the tutorial screens"
  ✓ "The password is in the password manager"
  ✓ "Tap the blue button, not the gray one"
  ✓ "Scroll down to see more options"

Bad context examples:
  ✗ "Do something"  (too vague)
  ✗ "Fix it"        (not actionable)
  ✗ "I don't know"  (not helpful)


## HOW CONTEXT AFFECTS LLM

WITHOUT your guidance:
  LLM sees: Intent, Screen, History
  
WITH your guidance:
  LLM sees: Intent, Screen, History, USER GUIDANCE
  
Result: Better decisions!


## WHEN AGENT ASKS FOR HELP

Automatically when:
  • Confidence < 50%
  • Multiple similar actions possible
  • Stuck on same screen
  • Uncertain about next step


## NON-INTERACTIVE MODE (Default)

  fathom run "your intent" --use-xml --serial emulator-5554 -v
  
  (No -i flag)
  
  • Fully automated
  • No questions asked
  • No pause/resume
  • Runs to completion
